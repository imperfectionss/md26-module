# Page 9 · Le matériel et les navigateurs compatibles

*Documentation de Kounach, logiciel de gestion pour commerçants. Kounach SARL, Casablanca. Entreprise, produit et chiffres fictifs, écrits pour le module MD-26.*

## Les navigateurs

Kounach fonctionne dans les deux dernières versions de Chrome, Edge et Firefox,
et dans Safari à partir de la version 17. Un navigateur plus ancien peut
afficher une page blanche, refuser la connexion, ou bloquer l'état des stocks.
Pour voir votre version, ouvrez le menu du navigateur, puis « Aide » et « À
propos ». La mise à jour est gratuite.

## Les ordinateurs et les tablettes

| Appareil | Minimum |
|---|---|
| Ordinateur | Windows 10 ou macOS 12, 4 Go de mémoire |
| Tablette Android | Android 10, écran de 8 pouces |
| iPad | iPadOS 16 |
| Téléphone | Consultation des chiffres seulement, pas d'encaissement |

## Les imprimantes de tickets

Les imprimantes thermiques de 58 et 80 millimètres qui acceptent le langage
ESC/POS, branchées en USB ou en réseau. Une imprimante Bluetooth fonctionne
avec une tablette Android, pas avec un ordinateur. Après le branchement,
lancez « Réglages », rubrique Matériel, bouton « Imprimer un ticket d'essai ».

## Les lecteurs de codes-barres

Tous les lecteurs qui se comportent comme un clavier, en USB ou en Bluetooth.
Pour vérifier, ouvrez un document vide et scannez un produit : le code doit
s'écrire tout seul.

## Le tiroir-caisse

Il se branche sur l'imprimante de tickets, qui l'ouvre à chaque vente en
espèces. Un tiroir branché directement sur l'ordinateur n'est pas reconnu.

## Les terminaux de paiement

Kounach transmet le montant aux terminaux compatibles de deux banques
partenaires, listés dans « Réglages », rubrique Paiement. Avec un autre
terminal, le caissier tape le montant sur le terminal lui-même, puis choisit
« Carte » dans Kounach.

## Une page blanche, une erreur à l'ouverture

Dans cet ordre : mettez le navigateur à jour, rechargez la page, essayez dans
une fenêtre de navigation privée. Si la page fonctionne en navigation privée,
une extension du navigateur bloque Kounach : désactivez les bloqueurs de
publicité pour l'adresse de Kounach. Attention, sur une caisse qui a des ventes
en attente d'envoi, ne videz pas les données du navigateur (page 3).
